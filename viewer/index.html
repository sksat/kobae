刺激

選んだ細胞集合に定常電流（30 mV 相当 × gain）を流します。点群は発火した細胞が白く光り、80 ms で減衰。ドラッグで回転、ホイールでズーム、クリックで細胞情報。

視覚 (R1-R6)

光受容体 3,335 個に輝度パターンを与える（下の左右の目マップに表示）。ラミナ L1-L5 の恒常電流も同時に入る。

ボタン

嗅覚 ORN（糸球体）

嗅覚受容ニューロン 2,635 個を糸球体（受容体型）ごとに。複数同時可。

自由指定

cell type を glob で検索して電流注入。ラスターもその集合に切り替わる。

superclass 発火レート (Hz/cell)

細胞クラスごとの平均発火率（直近 100 ms の指数平均）。ol = 視葉、cb = 中枢脳、vnc = 腹髄。

下行ニューロン読み出し (Hz)

DoomFly と同じ読み出し細胞。DNa02 = 旋回、DNp09 = 前進、MDN = 後退、MN9 = 吻伸展（摂食）、DNp20 / DNpe017 = 視覚応答性下行ニューロン。左右別。

ラスター

選択中の細胞集合の発火を時間軸で。横 = 直近 2 s、縦 = 細胞。
